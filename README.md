# Requirements

Before running this project, make sure that [.NET Framework 4.8](https://dotnet.microsoft.com/en-us/download/dotnet-framework/net48) is installed on your machine. This application was developed using .NET Framework 4.8 and may not function correctly if the required runtime is missing. If you do not already have it installed, you can download it from the official Microsoft website using the link above.

# Installation

1. Download or clone the repository.
2. Ensure that .NET Framework 4.8 is installed.
3. Build the app via VS Code, Rider or any other .NET IDE.
4. Start the application.
